# Make a user or group full admin of a Synapse entity

Convenience method to set admin permissions

## Usage

``` r
make_admin(entity, principal_id)
```

## Arguments

- entity:

  The Synapse entity, e.g. project or folder.

- principal_id:

  User/team name or id (e.g. "NF-OSI Sage Team", "3378999", "nf-bot", or
  "3423450") that will have the configured access to the entity.
