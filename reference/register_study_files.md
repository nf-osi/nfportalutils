# Register a project's files in **Portal - Files**

Add a project to the scope of the **Portal - Files** fileview so that
files for that project are "registered" and surfaced in portal.

## Usage

``` r
register_study_files(project_id, portal_fileview = "syn16858331")
```

## Arguments

- project_id:

  The project id, i.e. container, that will be added to the scope of the
  view.

- portal_fileview:

  Synapse id of "Portal - Files" entity view.
