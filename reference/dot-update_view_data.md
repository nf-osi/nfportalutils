# Replace/update table contents = input data must have ROW_ID, ROW_VERSION, ETAG columns to update.

Replace/update table contents = input data must have ROW_ID,
ROW_VERSION, ETAG columns to update.

## Usage

``` r
.update_view_data(table_id, new_data)
```

## Arguments

- table_id:

  The synapse id of the table to update.

- new_data:

  The updated table.
