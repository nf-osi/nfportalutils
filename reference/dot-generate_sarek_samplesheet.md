# Generate sarek samplesheet format

Generate sarek samplesheet format

## Usage

``` r
.generate_sarek_samplesheet(metadata, synstage, dataset_id)
```

## Arguments

- metadata:

  Data frame with dataset metadata

- synstage:

  Logical for Synapse staging

- dataset_id:

  Synapse dataset ID for staging

## Value

Data frame in sarek samplesheet format
