# Map sample input-output

Wrapper to map sample inputs and outputs depending on workflow type.

## Usage

``` r
map_sample_io(input, output)
```

## Arguments

- input:

  Data from `map_sample_input_ss`.

- output:

  Data from `map_sample_output_*`.

## Value

A table that includes `sample` `level` `output_id` `output_name`
`input_id`.
