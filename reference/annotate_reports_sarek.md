# Annotate Sarek reports

First runs `map_reports_sarek` under the hood.

## Usage

``` r
annotate_reports_sarek(syn_out, project, dry_run)
```

## Arguments

- syn_out:

  The `Reports` output folder which is set as scope for fileview.

- project:

  Project in which to put fileview.

- dry_run:

  Whether to submit annotations or just return the manifest.
