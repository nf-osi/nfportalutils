# Generate rnaseq samplesheet format

Generate rnaseq samplesheet format

## Usage

``` r
.generate_rnaseq_samplesheet(metadata, synstage, strandedness, dataset_id)
```

## Arguments

- metadata:

  Data frame with dataset metadata

- synstage:

  Logical for Synapse staging

- strandedness:

  Strandedness setting

- dataset_id:

  Synapse dataset ID for staging

## Value

Data frame in rnaseq samplesheet format
